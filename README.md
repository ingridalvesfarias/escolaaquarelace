# 🎨 Escola Aquarela — Institutional Website

Landing page institucional desenvolvida para a **Escola Aquarela**, instituição de ensino localizada em **Fortaleza/CE**, com atendimento do **Berçário ao 9º Ano**.

O projeto foi desenvolvido com foco em **performance, experiência do usuário (UX), SEO local, acessibilidade e responsividade**, combinando uma identidade visual lúdica e moderna com recursos interativos para apresentar a escola, suas unidades e sua rotina de forma atrativa.

---

## ✨ Sobre o Projeto

O objetivo do projeto foi criar uma presença digital que representasse a identidade da Escola Aquarela e, ao mesmo tempo, facilitasse o acesso dos responsáveis às principais informações da instituição.

A página foi estruturada para proporcionar uma navegação intuitiva, destacando:

* 🏫 Informações institucionais
* 📚 Etapas de ensino
* 📸 Galeria da rotina escolar
* 📍 Localização das unidades
* 💬 Contato e agendamento via WhatsApp
* 📱 Experiência otimizada para dispositivos móveis

---

## 🚀 Funcionalidades e Destaques

### 🔎 SEO & Open Graph

Implementação de estratégias de SEO para melhorar a presença do site nos mecanismos de busca e a forma como o conteúdo é apresentado quando compartilhado em redes sociais.

* Meta tags personalizadas
* Open Graph
* Meta description
* Title otimizado
* Informações para compartilhamento em WhatsApp, Facebook e LinkedIn

### 🧩 Dados Estruturados

Implementação de **Schema.org com JSON-LD**, utilizando `EducationalOrganization` para fornecer aos mecanismos de busca informações estruturadas sobre a instituição e suas unidades.

### 🎨 Design Moderno & Lúdico

Interface desenvolvida para transmitir a identidade visual da escola através de:

* Paleta de cores vibrante
* Tipografia personalizada
* Google Fonts — **Baloo 2** e **Inter**
* Elementos gráficos em SVG
* Animações e microinterações
* Hierarquia visual focada na experiência do usuário

### 🖼️ Galeria Interativa

Seção dedicada à apresentação da rotina escolar através de um **carrossel interativo**, permitindo uma navegação visual e dinâmica pelas imagens.

### 📍 Google Maps

Integração com o **Google Maps** para apresentar a localização das duas unidades da instituição, facilitando o acesso dos responsáveis às informações de cada sede.

### 💬 CTAs Estratégicos

Botões de chamada para ação distribuídos ao longo da página para facilitar a conversão dos visitantes.

Incluindo:

* Agendamento de visita
* Contato via WhatsApp
* Botão flutuante de WhatsApp
* Acesso rápido às unidades

### 📱 Design Responsivo

O layout foi desenvolvido seguindo uma abordagem responsiva, garantindo uma experiência consistente em:

* 📱 Smartphones
* 📲 Tablets
* 💻 Notebooks
* 🖥️ Desktops
